# Express + PostgreSQL (Single File Version)

هذا المشروع بسيط جدًا والغرض منه التعلم فقط.

## المتطلبات
- Node.js
- PostgreSQL
- جدول باسم capitals

## تشغيل المشروع
1. npm install express pg
2. node server.js
3. افتح المتصفح:
   http://localhost:3000/capitals

## ملاحظات
- الاتصال بقاعدة البيانات يتم مرة واحدة
- نستخدم async/await فقط
- كل الكود في ملف واحد للتعلّم
