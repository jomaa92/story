# ⚙️ البنية المعمارية (Architecture)

## 1️⃣ Database Layer

مسؤولة عن الاتصال بقاعدة البيانات وتنفيذ الاستعلامات.

## 2️⃣ Service Layer

تحتوي منطق العمل.

### UserService

-   جلب المستخدمين
-   جلب مستخدم محدد
-   إنشاء مستخدم جديد

### CountryService

-   البحث عن دولة
-   جلب الدول التي زارها مستخدم
-   إضافة دولة جديدة

## 3️⃣ AppState

يدير: - المستخدم الحالي - قائمة المستخدمين - تحديث الحالة

## 4️⃣ Routes

تتعامل مع استقبال الطلبات وإرسال البيانات للقوالب.

------------------------------------------------------------------------

# 🧱 المبادئ البرمجية المستخدمة

## ✅ Separation of Concerns

كل جزء مسؤول عن شيء واحد فقط.

## ✅ DRY -- Don't Repeat Yourself

لا تكرر نفس الكود أكثر من مرة.

## ✅ Error Handling

استخدم try/catch دائمًا وتعامل مع الأخطاء بوضوح.

------------------------------------------------------------------------

# 🔍 منهجية تصحيح الأخطاء (Debugging)

-   استخدم console.log بذكاء
-   تحقق من كل خطوة على حدة
-   اطبع تفاصيل الخطأ (message, stack)

------------------------------------------------------------------------

# 📊 تدفق البيانات داخل التطبيق

1.  المستخدم يرسل طلب
2.  Route يستقبل الطلب
3.  Service تنفذ المنطق
4.  Database تنفذ الاستعلام
5.  البيانات تعود للواجهة
